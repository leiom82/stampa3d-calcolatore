# 🖨️ Calcolatore Costi Stampa 3D — OTAKU3DLAB

Strumento gratuito e open source per calcolare il prezzo corretto delle tue stampe 3D, sviluppato da **OTAKU3DLAB**.

Inserisci i dati dallo slicer, seleziona la tua stampante e il tuo fornitore energetico — il prezzo di vendita consigliato si calcola in tempo reale, tenendo conto di tutti i costi reali: materiale, elettricità, ammortamento, usura, failure rate, manodopera e guadagno.

---

## ✨ Funzionalità

- **50+ stampanti** nel menu a tendina — Bambu Lab, Anycubic, Creality, Flashforge, QIDI, Elegoo, Prusa, Snapmaker
- **30+ fornitori energetici italiani** con prezzi aggiornabili tramite `tariffe.json`
- **Sezione accessori** — inserti filettati, NFC tag, magneti al neodimio, calamite, viti, colla, imballaggio, spedizione
- **Grafico ripartizione costi** interattivo
- **Glossario** di tutte le voci con formule ed esempi
- **Guida all'uso** integrata
- Funziona **offline** — cade automaticamente su prezzi di fallback se non c'è connessione

## 🔄 Aggiornare i prezzi energia

1. Apri `tariffe.json` e clicca ✏️ su GitHub
2. Modifica i valori `"prezzo_kwh"` dei fornitori (usa il **punto**, non la virgola)
3. Aggiorna il campo `"aggiornato"` con la data odierna
4. Clicca **Commit changes** — i nuovi prezzi sono live in 1-2 minuti
